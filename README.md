# purview-data-classification-framework

## Overview
This repository provides a practical framework for designing and implementing
data classification using Microsoft Purview. It is intended for organisations
seeking a structured approach to identifying, classifying, and governing
sensitive data across cloud and enterprise data sources.

## Problem Statement
Many organisations struggle to consistently identify and classify sensitive
data, leading to compliance risks, poor data visibility, and weak governance
controls. Microsoft Purview provides powerful capabilities, but organisations
often lack practical templates and guidance to implement it effectively.

## Solution
This repository offers:
- Reusable data classification templates
- Governance mappings aligned to common standards
- Practical implementation guidance for Microsoft Purview
- Documentation to support security and compliance teams

## Use Cases
- Data governance and compliance reporting
- Information protection and risk assessment
- Security posture improvement
- Audit preparation

## Classification Model
Data is grouped into four sensitivity tiers
- Public
- Internal
- Confidential
- Highly Confidential
Each Tier Includes
- Description
- Example data types
- Recommended protection controls

## Tools and Concepts Used
- Microsoft Purview
- Sensitivity Labels
- Auto - Labelling concepts
- Compliance posture review
- Risk-based classification approach

## Limitations
This framework is provided as a reference implementation and should be adapted
to organisational requirements, regulatory environments, and risk appetite.
